### 标题栏在鼠标悬浮时会跳变

标题栏在鼠标悬浮时由于会显示文件图标，导致宽度增加，发生跳变。建议移除标题栏玻璃效果，将左侧对比文件名在界面中线处右对齐，右侧对比文件名在中线处左对齐，并使用标准标题栏。这样直接解决了以下问题：

1. 玻璃内容变化导致玻璃宽度变化，布局不稳定。
2. 玻璃高度过高导致超出标准标题栏需要自己绘制，偏离原生设计初衷。
3. 在窗口高度过窄时，标题始终存在。
4. 用户不再有点击玻璃容器会触发文件选择的心理暗示，可以更加从容地在更大的区域拖动窗口，扩大了心理上窗口标题栏的控制区域。

若实现以上任意情况时出现困难，可以考虑整体加高标题栏到当前水平，并确保标题栏在任何合理窗口大小都能够正常固定。

### 标题栏文件拖拽图标

拖拽图标时，没有禁用窗口拖移操作和点击文件名浏览文件选择器的功能，导致此功能不可用。注意：拖拽图标的含义就是字面含义，只有拖放图标能够生效等效于拖放文件本身的效果，拖动任何其他部分都是移动窗口，点击文件名是打开文件选择器。
